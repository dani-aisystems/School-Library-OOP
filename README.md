# School Library OOP

Конзолно приложение на C#, което моделира училищна библиотека.

Проектът демонстрира:

- класове и обекти;
- конструктори;
- енкапсулация с `private` и `protected`;
- наследяване от базовия клас `Person`;
- работа с `List<T>`;
- заемане и връщане на книги.

## Класове

- `Book` - съхранява информацията за една книга;
- `Person` - базов клас за личните данни;
- `Librarian` - добавя книги и регистрира читатели;
- `Reader` - заема и връща книги;
- `Program` - демонстрира работата на приложението.

## Стартиране

Необходим е .NET 10 SDK. От папката на проекта изпълнете:

```bash
runner=$(mktemp -d)
dotnet new console -o "$runner" -f net10.0
cp *.cs "$runner"
dotnet run --project "$runner"
```

Хранилището съдържа само изходния код и няма включен `.csproj` файл.
